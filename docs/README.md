# Feed documentation

Read the [documentation website](https://dereuromark.github.io/cakephp-feed/), starting with [Installation](https://dereuromark.github.io/cakephp-feed/guide/installation) and [Getting started](https://dereuromark.github.io/cakephp-feed/guide/getting-started).

Run `npm ci` and `npm run docs:dev` in this directory for local development; `npm run docs:build` checks publication.
